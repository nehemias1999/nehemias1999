## About Me

DevOps / MLOps engineer focused on running production applications and shipping software end to end. I build and operate CI/CD pipelines with **Jenkins** and **Azure DevOps**, manage hybrid infrastructure across **Linux, Windows, Docker and the cloud (GCP, AWS)**, and bring **GenAI deployments and AI-agent automations** into production — including regulated banking and retail environments.

I design declarative, reviewable "as-code" tooling for infrastructure and account-level resources, treating security (no secrets in code) and reproducibility as first-class concerns.

## What I Do

- **Infrastructure as Code** — declarative, reviewable automation for cloud and DevOps resources, with plan/apply-style safety (never deletes, never commits secrets).
- **CI/CD end to end** — pipelines from commit to production on Jenkins, Azure DevOps, GitHub Actions and GitLab CI.
- **Containers & Cloud** — Docker-based delivery and hybrid on-prem/cloud infrastructure on Linux, Windows, GCP and AWS.
- **GenAI & MLOps** — production deployments of generative AI and autonomous AI-agent harnesses.
